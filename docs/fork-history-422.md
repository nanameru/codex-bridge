# 分岐チャットの履歴復元422（Issue #169）

Codexの分岐ログには、子の `session_meta` に続いて親の `session_meta` と
継承した `compacted` が記録される場合がある。従来は分岐を一律拒否していたため、
親の元ログが存在しても履歴引き継ぎが422で停止した。

分岐ログの所有者・ID・巻き戻し有無・要求checkpointを検証したうえで、
`forked_from_id` の親を同じ読み取り専用処理で検証する。親にも完全一致する
checkpointがある場合だけ、親の元履歴と今回の要求を使用する。
`replacement_history` の平文だけで欠けた元履歴を代用しない。

先頭以外の追加metadata、親ID不一致、親ログ欠落、checkpoint不一致、
循環参照、8ログを超える分岐、巻き戻し、安全でないファイルは拒否する。
親にない子独自のcheckpointはこの経路では復元できない。
本人のログ・暗号化履歴は変更しない。

検証は `test/history-mode.test.mjs`。分岐成功時のルーターHTTP200、最新要求と
ツール結果の保持、各拒否条件、深さ上限、原本の不変性を合成ログで確認する。
