## 競合解消

旧PRで同じ番号が別の用途に割り当てられていたテストケースは、master側の既存IDを保持し、スレッド別ガードをTC-050、上流障害再試行をTC-051、thinking互換をTC-052へ割り当てた。Issue紐付けは保持する。

可搬圧縮用mockの「ツール定義あり」の条件と、最新の「回答復帰ではツールなし」の条件を両方保持する。HTTPテストは旧版で置換せず、本人認証・画像データ・秘匿ログの検証にスレッド別429と上流Retry-Afterを追加する。

## 検証範囲と制約

Node/Python全件、shell構文、Python構文、模擬上流に対する実Codex app-serverの文章圧縮4パターン、暗号化圧縮からの引き継ぎ成功/失敗、実Chat bridgeのlength復帰とツール制限を確認する。実APIへの会話再送や全モデル品質の保証は含めない。

Issue #51の実モデルHY4の応答マーカー欠落は原因未解明。64回のツール予算は長い正常なタスクにも作用し得る。画像originalはOpenCode向けにhighへ互換変換するため、元モデル固有のoriginal処理と同一とは限らない。フック134のPython環境破損は対象外。

GitHub masterの更新と、各利用者環境の常駐プロセスの更新は別。今回のGitHub統合作業では、利用中のMacのプロセスを追加で再起動しない。
